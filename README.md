
# Complex Number Calculator in C++

A simple C++ mini-project that performs addition and subtraction of two complex numbers using operator overloading.

## Features
- Addition of complex numbers
- Subtraction of complex numbers
- Operator overloading
- Invalid input handling

## OOPS Concepts
- Classes and Objects
- Constructors
- Encapsulation
- Operator Overloading

## How to Run

Compile:
```bash
g++ main.cpp -o calculator
```

Run:
```bash
./calculator
```

On Windows, run:
```bash
calculator.exe
```

## Example
Input:
- First number: 4 + 3i
- Second number: 2 + 1i

Output:
- Addition: 6 + 4i
- Subtraction: 2 + 2i
